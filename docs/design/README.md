# Design reference availability

The original `reference.png` and `chart-target.png` are private, locally retained
design inputs. Their public redistribution rights have not been established, so
they are intentionally excluded from Git and public source archives. They are
not required to build or run PulseView.

Public contributors should use the actual application captures in
[`../screenshots/`](../screenshots/) together with [`../THEMES.md`](../THEMES.md)
and the product invariants in [`../../agent.md`](../../agent.md). If the original
references are available locally, they remain the approved visual target.
Do not add them to Git without establishing redistribution permission.
