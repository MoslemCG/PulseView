# PulseView 1.1.1

- Added a labeled **About** button with the version in the footer.
- Added **About PulseView** to pane right-click menus, including Charts-only mode.
- Shortened the README and corrected the version instructions.

**Setup:** download `PulseView-Setup-x64.exe`, run it, then open PulseView from Start.

**Portable:** extract `PulseView-Portable-x64.zip` and run `PulseView.exe`. Keep the included UI and DLLs together.

Windows 11 x64 required. Setup installs WebView2 if missing and preserves existing presets. The installer is unsigned. Checksums are in `SHA256SUMS.txt`.
